# Locket privacy policy

Locket is a clipboard manager for Windows. This policy covers the Locket app from the Microsoft Store
and the builds published on GitHub.

## What Locket collects

Nothing. Locket has no analytics, no telemetry, no crash reporting and no accounts.

## Your clipboard history

Locket saves what you copy so you can use it again. That history stays on your device, in the app's
local data folder (`%LOCALAPPDATA%\Packages\MarshallHD.Locket_*\LocalState`). It is never sent
anywhere. You can delete single items or clear the history in Locket at any time, and uninstalling
Locket removes the folder.

Locket does not save copies that password managers and other apps mark as private, and you can add
your own rules in *Settings → Ignore*.

## Network access

Locket installed from the Microsoft Store makes no network requests; the Store handles updates.

Builds installed from GitHub instead check for a new version on GitHub once a day, while
*Check for updates automatically* is on in *Settings → General*. The check asks GitHub for the
latest release of Locket and sends nothing about you or your clipboard. GitHub's own
[privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)
applies to that request.

Links in *About* open in your browser only when you click them.
